About This Deck

The Generative Tarot is a procedurally-rendered deck built with p5.js. Every card is drawn algorithmically — no static images, only mathematics and code.

How It Works

Each card uses a seeded pseudo-random number generator. A given seed always produces the same visuals, making readings reproducible. Different seeds yield visual variations within each card's archetypal grammar.

The 78 Cards

  • 22 Major Arcana — The Fool through The World. Each has a unique geometric motif encoding its symbolic meaning.
  • 56 Minor Arcana — Four suits (Cups, Wands, Swords, Pentacles) of 14 cards each.

Spreads

  • Single Card — A daily draw or focused question
  • Three Card — Past · Present · Future
  • Celtic Cross — Ten-card comprehensive reading
